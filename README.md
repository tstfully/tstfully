## 🆕 Turn YouTube videos into something useful

Free AI skills for Claude. Paste a YouTube link, get something you can present, study, or share.

📊 [**youtube-to-case-study**](https://github.com/tstfully/youtube-to-case-study) ![stars](https://img.shields.io/github/stars/tstfully/youtube-to-case-study?style=social&label=%E2%AD%90)
<br>Turn any video into a business, marketing, UX, or growth **case-study slideshow**, with every fact linked to the exact second it was said.
<br><sub>Great for 📣 marketers · 💼 consultants · 🍎 educators</sub>

🎓 [**youtube-to-course**](https://github.com/tstfully/youtube-to-course) ![stars](https://img.shields.io/github/stars/tstfully/youtube-to-course?style=social&label=%E2%AD%90)
<br>Turn any video into an **interactive course** with bite-sized lessons, quizzes, flashcards, and confetti. 🎉
<br><sub>Great for 🍎 educators · 🎓 learners · 🏢 team trainers</sub>

💬 [**youtube-to-ai-chat**](https://github.com/tstfully/youtube-to-ai-chat) ![stars](https://img.shields.io/github/stars/tstfully/youtube-to-ai-chat?style=social&label=%E2%AD%90)
<br>**Ask any video anything.** Answers cite the exact moment, and you can build a shareable "ask this video" page.
<br><sub>Great for 🔬 researchers · 🎙️ content creators · 📣 marketers</sub>

**Get all three in Claude Code:**

```
/plugin install youtube-to-case-study --marketplace tstfully/youtube-to-case-study
/plugin install youtube-to-course --marketplace tstfully/youtube-to-course
/plugin install youtube-to-ai-chat --marketplace tstfully/youtube-to-ai-chat
```

✨ **New to vibe coding?** Every project has a "just ask" section with copy-paste prompts, and works in Claude.ai with no install.

Open-source building blocks to put YouTube content into your own apps and AI workflows.
